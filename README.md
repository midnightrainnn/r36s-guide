# R36S Quick Start

An interactive, phone-friendly manual for the R36S handheld. Tap the buttons on the drawn console to learn how to power it on, start and exit a game, save and load, change volume and brightness, and shut down safely.

Open it here: https://midnightrainnn.github.io/r36s-guide/

The whole page is a single file, `index.html`, with no build step.
